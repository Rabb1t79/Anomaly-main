## 用途与边界
用于检索仓库中的 NTE 原生 Dump。这里是源码导航与证据记录，不替代原始 Dump，也不把路径/命名推断当作已证实机制。

## 读取限制
- 旧版 Dump 的大文件可通过 Git blob 读取；索引存在不表示所有正文已逐句审阅。
- 新版 Dump 通过当前文件读取接口返回 Git LFS 指针，而非真实源码正文。Git blob SHA/size 指向指针 blob，不是 LFS 实体内容/大小。
- 不从外部 SDK、通用 UE 文档或未获用户授权的资料补齐结论。
- 本轮以仓库目录为来源，不以 ZIP 文件作为证据。

## 注释等级
1. **路径初注**：根据文件名、目录、扩展名提供导航说明，未读正文。
2. **正文已读**：实际读取源码后对声明/内容摘要。
3. **同源交叉核验**：由参数结构、函数包装或 Dumpspace 元数据支持。
4. **运行时未证实**：Dump 声明存在不等于目标功能使用它，也不等于它是受支持插件接口。

## 规划
- `file-index-*.md`：全量路径索引，包含扩展名、Git blob size、SHA 和初注。
- `damage-chain-candidates.md`：伤害触发候选类型的正文证据。
- `version-diff.md`：两版对照状态和阻塞项。
- 后续补类/结构/函数/参数布局索引、逐文件摘要和调用关系索引。
