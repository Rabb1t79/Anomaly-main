# 持续工作进度记录

本目录用于在不同聊天之间承接插件开发、研究、复现和维护工作。它是工作状态索引，不替代项目源代码、任务规范或验证日志。

## 更新规则

- 每个工作日/工作段使用 `YYYY-MM-DD.md` 记录。
- 每累计 4 项实质操作，或开始第 5 项实质操作前，写入一次进度检查点；构建、交付、切换分支或即将中断时提前记录。
- 记录仓库/分支/提交、材料身份、已完成事项、证据状态、未决问题和下一步。
- 明确区分“直接证实”“有证据支持但未验证”“未知”。
- 只记录真实执行结果；不得把构建成功写成实机成功，也不得把假设写成事实。
- 任何新任务先读本索引与最新日期记录；不同插件/任务各自定义目标，不自动沿用当前任务的实现路线。
- 不记录密钥、令牌、个人敏感数据，不把 Dump 或解密材料本体复制到运行包。
