# Legacy plugin sources

These plugins are retained only as source references for historical investigation. They are intentionally outside the `plugins/` directory, which the current Anomaly Core scans for installable plugin packages.

- `NteAttackReplay/`: the retired Attack Replay route. Do not install alongside the independent Damage Chain Reaction plugin.
- `NteDamageChainReaction/`: an older implementation preserved for source comparison.

The active independent implementation is `plugins/DamageChainReaction/`.
